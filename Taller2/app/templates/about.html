About This Project

Yelp Hybrid Recommendation System

A sophisticated recommendation system that combines collaborative filtering and context-aware recommendations to provide personalized business suggestions.

Project Overview

This recommendation system is a part of the MINE4201-01 Recommendation Systems course (2025-1). It leverages real Yelp data to provide users with personalized business recommendations based on their past behavior and contextual information.

Key Features
Collaborative Filtering

Our system analyzes patterns of user behavior to identify users with similar preferences. It then recommends businesses that similar users have enjoyed.

  • Matrix factorization techniques
Context-Aware Recommendations

Our system considers contextual factors when making recommendations:

  • Time of day (morning, afternoon, evening, night)
  • Day of the week
  • Season
  • Location/City
Explainable AI

Our system provides explanations for why a particular business is recommended, increasing transparency and user trust:

  • Collaborative-based explanations
  • Similar user explanations
  • Contextual explanations
  • Category-based explanations
User Feedback

Our system learns from user feedback to continuously improve recommendations:

  • Like/dislike buttons for recommendations
  • Continuous model updating
  • Personalization based on feedback

Technical Details

The application is built using:

  • Backend: Python, FastAPI
  • Frontend: HTML, CSS, Bootstrap, JavaScript
  • Data Visualization: Matplotlib, Seaborn, Folium
  • Machine Learning: Scikit-learn, NumPy, Pandas, Surprise
Dataset

This system uses the Yelp Dataset, which includes:

  • Business data (location, categories, attributes, etc.)
  • User data (review history, friend connections, etc.)
  • Review data (ratings, text, dates, etc.)
